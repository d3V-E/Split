#2 player game

In this game you need to play it with a friend on one computer
Controls

P1 = S
P2 = K

The orange button resets both player score


The instructions button can explain it in more detail and contains instructions for each game

There are 4 games

Game 1 (Timer game) = A time is given the user who clicks nearest to the time wins

Game 2 (Green bar) = You click when the needle is on the green bar (You might have to click twice for it to register it properly)

Game 3 (Quick Shot) = When the countdown the says go the first to press their control shoots and wins (Animations takes a bit of time)

Game 4 (Spam) = You have 60 sec to click as much score as possible
